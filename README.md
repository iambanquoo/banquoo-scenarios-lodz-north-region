# Overview
*Banquoo Scenarios: Łódź North Region DLC* is a community-made package of scenarios developed for the game *SimRail - The Railway Simulator*, for those who own the *Łódź North Region* DLC. It contains full audio tracks, scenario configuration (rolling stock, weather etc.), and full English support. Check out how to install this scenario package and more, by scrolling below!

Below You can find a list of scenarios currently available in-game with this mod:
- [Cargo] Łódź Chojny - Kutno

It is also worth noting, that the scenarios are made in a vanilla-like style. Therefore, we use the same libraries as the official in-game scenarios developed by Eridor. The libraries provided are his, not ours.
# Installation
## Automatic download (Steam Workshop)
The scenario package can be downloaded easily by subscribing to it on the Steam Workshop. Simply visit [this link](https://steamcommunity.com/sharedfiles/filedetails/?id=3783121873) and press **subscribe**. The mod should be downloaded automatically by the Steam Client, and the next time You run the game it should appear in the scenery selection menu.  
<img width="678" height="149" alt="steam_workshop" src="https://github.com/user-attachments/assets/97d92157-d9b4-43a9-a810-b5a287c3e47b" />

## Manual download (via GitHub)
The package can also be downloaded manually, without the use of Steam's Workshop module. To do so, follow the steps below.
1. Download a version of choice from the GitHub repository. We recommend the **latest** version.
2. Extract the downloaded archive anywhere You'd like.
3. Copy the extracted folder with scenery files inside (usually with files like *SceneryManifest.xml, Map.png, and libs folder*) and paste it into ``SimRail/SimRail_Data/StreamingAssets/Sceneries``.
4. Restart Your game
5. Enjoy :P
